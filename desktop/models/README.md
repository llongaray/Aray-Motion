# Modelos MediaPipe

Coloque nesta pasta os modelos oficiais compatíveis com MediaPipe Tasks:

- `hand_landmarker.task` — Hand Landmarker
- `face_landmarker.task` — Face Landmarker

Fontes e documentação:
- https://ai.google.dev/edge/mediapipe/solutions/vision/hand_landmarker
- https://ai.google.dev/edge/mediapipe/solutions/vision/face_landmarker

Os modelos não estão versionados. Antes de distribuir o ZIP, o workflow deve obter os modelos de fontes verificadas e empacotá-los. A versão inicial do workflow não inclui os modelos e, portanto, o ZIP produzido é apenas uma prévia técnica e não um release pronto para o usuário final.
